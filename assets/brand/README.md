# GRELECY visual assets

The repository presentation uses the selected Hardware Legacy direction: a graphics-card-shaped G emblem with an emerald PCB, silver metal, circuit traces, and gold contacts.

| File | Format | Intended use |
| --- | --- | --- |
| [grelecy-logo.png](grelecy-logo.png) | 1254 × 1254 PNG, transparent background | Standalone emblem, community avatar source, and project documentation |
| [grelecy-banner.png](grelecy-banner.png) | 2172 × 724 PNG | README header and wide project presentation |

![GRELECY repository banner](grelecy-banner.png)

## Usage

Keep the original proportions and adequate clear space. Do not stretch, recolor, or remove parts of the emblem. Check readability at the actual display size, especially when using it as an avatar. The logo includes transparent padding; preview circular crops before use.

The assets were prepared from the project's visual exploration boards using Imagegen. They are raster artwork; no editable vector master is provided.

## GitHub placement

The banner is embedded in the root README. Personal repositories do not have their own profile avatar; GitHub displays their owner's account avatar. An organization avatar and a repository social preview are separate GitHub settings and are not changed by committing these files.
