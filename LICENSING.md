# Licensing

GRELECY separates software, documentation, and brand permissions. This file explains the scope of the licenses included in this repository; it does not modify their terms.

## Software: MPL-2.0

Original software source code contributed to this repository is licensed under the **Mozilla Public License 2.0**, unless a file or its directory explicitly states otherwise. The complete, unmodified license is in [LICENSE](LICENSE).

Mark new source files with the following notice in the appropriate comment syntax:

```text
SPDX-License-Identifier: MPL-2.0
```

The MPL uses file-level copyleft. When covered software is distributed, the applicable source availability and notice requirements must be met. Separate files containing no MPL-covered code may have different terms, subject to the license. The [license text](LICENSE) controls; Mozilla's [MPL FAQ](https://www.mozilla.org/en-US/MPL/2.0/FAQ/) provides further explanation.

No additional "Incompatible With Secondary Licenses" designation is applied by this repository. The presence of Exhibit B in the standard license text is not itself such a designation.

There is no software source code in this initial community setup. This policy does not prescribe a license for all future GRELECY repositories or driver projects. Those projects must state their own terms before accepting contributions.

Except for separately identified material, GRELECY's original prose documentation and the text of its contribution templates are licensed under **Creative Commons Attribution 4.0 International**.

This includes README.md, CONTRIBUTING.md, LICENSING.md, the prose policy in BRANDING.md, and the original text in .github/ISSUE_TEMPLATE/. It excludes license texts, third-party quotations and material, software examples explicitly marked with another license, and brand assets themselves.

The complete license is in [LICENSES/CC-BY-4.0.txt](LICENSES/CC-BY-4.0.txt). An accessible summary is available from [Creative Commons](https://creativecommons.org/licenses/by/4.0/).

When sharing this documentation, retain supplied attribution and notices, provide a license link, and indicate modifications as required by the license. A suggested attribution is:

> GRELECY contributors, *GRELECY — Green Legacy Community*, https://github.com/FaipL/Grelecy, CC BY 4.0. Changes: describe your changes, if any.

Preserve any supplied individual author credits. Contributors retain the copyright in their contributions; no copyright assignment is required.

Keep third-party license notices intact and identify the upstream source, version, and applicable license whenever third-party material is accepted. Link to upstream downloads when redistribution rights have not been established.
