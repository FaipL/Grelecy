- Un aperçu permet de vérifier le contenu avant de le copier ou de l’enregistrer en Markdown ou JSON. Le formulaire GitHub correspondant s’ouvre séparément : **aucune donnée n’est envoyée automatiquement**. Publier sur GitHub nécessite un compte et rend le contenu public.

**Pour essayer :** télécharger l’archive jointe **GRELECY-Diagnostics-0.2.0-preview.1-win-x64.zip**, l’extraire, puis ouvrir **GRELECY-Diagnostics.exe** par double-clic. La cible est **Windows 10/11 x64** ; le runtime .NET est inclus, sans installation de .NET ni droits administrateur nécessaires. ARM64 et Windows 32 bits ne font pas partie de ce paquet.

**Vérifications :** les 15 tests du cœur, les contrôles automatisés de l’interface et de la collecte WMI sous Windows, ainsi que l’ouverture et la fermeture de l’exécutable distribué ont réussi. Le collecteur 0.1 a également été essayé avec succès par l’initiateur du projet. Les nouveaux parcours sur des PC personnels, la diversité du matériel, les affichages à forte mise à l’échelle et Narrateur restent à valider.

L’exécutable n’est pas signé : Windows peut afficher un avertissement d’éditeur inconnu. Respectez les protections de Windows. L’outil ne fournit ni pilote ni correctif, ne mesure pas les performances et n’annonce aucun gain. Un essai réussi décrit uniquement le scénario rapporté, sans garantie générale de compatibilité.

## English

**GRELECY Diagnostics 0.2 adds two guided ways to contribute: report a problem or share a successful test.** This prerelease is a Windows prototype, not a stable release.

- Three steps in French or English: identify the game or application, describe the test, then review the report. Answers survive backward navigation and language changes.
- Windows and GPU configuration is optional. Unknown information can remain blank; unavailable collection does not prevent you from preparing your statement.
- Preview the content before copying it or saving it as Markdown or JSON. The matching GitHub form opens separately: **nothing is uploaded automatically**. Posting on GitHub requires an account and makes the contribution public.

**To try it:** download the attached **GRELECY-Diagnostics-0.2.0-preview.1-win-x64.zip**, extract it, then double-click **GRELECY-Diagnostics.exe**. The target is **Windows 10/11 x64**; .NET is included, with no separate .NET installation or administrator rights required. ARM64 and 32-bit Windows are not included in this package.

**Checks:** all 15 core tests, automated Windows UI and WMI collection checks, and opening and closing the packaged executable passed. The project initiator also successfully tried the 0.1 collector. The new guided paths on personal PCs, different hardware, high display scaling and Narrator still need validation.

The executable is unsigned, so Windows may show an unknown-publisher warning. Respect Windows protections. The tool provides no driver or patch, does not measure performance and promises no performance gains. A successful test describes only the reported scenario, without guaranteeing general compatibility.
