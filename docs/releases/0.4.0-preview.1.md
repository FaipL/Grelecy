# GRELECY Diagnostics 0.4.0-preview.1

## Français

Cette préversion ajoute **Tests automatiques**, un parcours distinct des rapports de configuration et des récits d'utilisateurs. L'utilisateur recherche les cartes, choisit explicitement celle à tester et lance un calcul court.

- Vérification de la création Direct3D 11 et d'un calcul entier déterministe avec contrôle complet des résultats.
- Trois passages de préparation, cinq mesures par horloge GPU, puis minimum, médiane, maximum et valeurs brutes si le test est valide.
- Sonde du pilote CUDA : API exposée et capacité de calcul de la même carte, sans lancement d'un modèle d'IA.
- Mémoire dédiée lue via DXGI, options de partage, copie Markdown et export Markdown/JSON.
- Processus isolé, annulation et délai global de 45 secondes, 14 langues, thème Windows et arabe de droite à gauche.

Les durées sont celles d'une **charge synthétique précise** : elles ne donnent pas les FPS d'un jeu, les tokens/seconde d'une IA, ni un verdict général de compatibilité. Les résultats incomplets ou invalides n'affichent aucun score. Les tests de développement WARP sont identifiés comme logiciels et n'exportent aucune performance GPU.

La cible reste Windows 10/11 x64. Le prototype est non signé. Il n'installe aucun pilote, ne modifie aucun firmware et n'envoie aucun rapport automatiquement. Les schémas des anciens rapports sont conservés ; les tests automatiques disposent de leur propre schéma.

**État de validation :** compilation et tests de rapports ne remplacent pas une exécution Windows ni un essai sur les cartes du périmètre. La CI Windows, le worker WARP et le paquet portable doivent être vérifiés avant publication. Les essais physiques Kepler, Maxwell, Pascal et GTX 16 doivent être documentés séparément. Aucun gain matériel GRELECY n'est revendiqué par cette version.

## English

This preview adds **Automatic tests**, separate from configuration reports and user observations. Users enumerate adapters, explicitly select a card and start a short workload.

The implementation verifies D3D11 creation and deterministic integer compute output; collects five GPU timestamp samples after three warm-ups; probes the matching CUDA driver API and compute capability; and exports reviewed Markdown/JSON with optional graphics/PCI information. It runs in an isolated, cancellable worker with a 45-second deadline. All 14 languages, Windows appearance and Arabic RTL are retained.

Synthetic durations are not game FPS, AI throughput or a universal compatibility verdict. Incomplete/invalid results cannot produce a score. WARP developer checks remain explicitly software and never export GPU performance. Existing report schemas remain unchanged.

Windows 10/11 x64 remains the package target. The prototype is unsigned, changes no driver/firmware and uploads nothing automatically. Windows CI, the WARP worker and the packaged executable must be verified before publication; physical-GPU acceptance is separate. No GRELECY hardware performance gain is claimed.
