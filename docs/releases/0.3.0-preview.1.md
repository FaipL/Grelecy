## Français

**GRELECY Diagnostics 0.3 suit maintenant le thème de Windows, propose 14 langues et affiche le logo officiel du projet.** Cette version d'essai poursuit les deux parcours : signaler un problème et partager un essai réussi.

- Mode clair ou sombre selon le réglage des **applications Windows**, actualisé pendant que les fenêtres sont ouvertes. Le contraste élevé de Windows reste prioritaire.
- Interface, aperçu et rapports Markdown/texte en français, anglais, italien, espagnol, allemand, néerlandais, portugais européen, chinois simplifié, coréen, japonais, arabe, polonais, suédois et norvégien bokmål. La langue de Windows est proposée au démarrage quand elle est prise en charge ; sinon, l'anglais est utilisé. Un sélecteur permet de changer sans perdre le récit ni le relevé.
- Mise en page de droite à gauche pour l'arabe, avec conservation des noms techniques et des réponses multilingues. Le JSON garde son schéma et ses clés indépendants de la langue.
- Logo GRELECY dans les deux en-têtes et icône officielle pour la fenêtre, la barre des tâches et l'exécutable.

Télécharger **GRELECY-Diagnostics-0.3.0-preview.1-win-x64.zip**, extraire l'archive puis ouvrir **GRELECY-Diagnostics.exe**. Windows 10/11 x64 est la cible ; .NET est inclus et les droits administrateur ne sont pas nécessaires. Le paquet inclut son guide, ses licences et les notices Microsoft.

Les contrôles automatisés couvrent les catalogues, les 14 langues, les rapports, la conservation des réponses, les thèmes, le contraste élevé, le logo et les parcours Windows, ainsi que le lancement de l'exécutable distribué. La relecture des nouvelles traductions par des locuteurs natifs et les essais avec Narrateur, différentes mises à l'échelle et du matériel personnel restent à effectuer. Les dialogues natifs, comme le choix d'un fichier, suivent les réglages et traductions de Windows.

Le programme reste un **prototype non signé** : Windows peut afficher un avertissement d'éditeur inconnu. Il ne fournit aucun pilote, ne mesure ni les performances ni la compatibilité et n'envoie aucun rapport automatiquement. Toute publication sur GitHub est volontaire, publique et nécessite un compte. Un essai réussi concerne seulement le scénario décrit.

Code sous MPL-2.0, documentation sous CC BY 4.0. Le logo conserve la [politique de marque](https://github.com/FaipL/Grelecy/blob/main/BRANDING.md). [Guide complet](https://github.com/FaipL/Grelecy/blob/main/docs/DIAGNOSTICS.md).

## English

**GRELECY Diagnostics 0.3 follows the Windows theme, offers 14 languages and displays the official project logo.** This preview retains both guided paths: report a problem and share a successful test.

- Light/dark appearance follows the Windows **application** preference, including changes while windows are open. Windows high contrast takes priority.
- Interface, preview and Markdown/text reports in French, English, Italian, Spanish, German, Dutch, European Portuguese, Simplified Chinese, Korean, Japanese, Arabic, Polish, Swedish and Norwegian Bokmål. Startup uses the supported Windows UI language or falls back to English. The picker preserves answers and configuration when switching languages.
- Right-to-left Arabic layout with multilingual answers and technical names preserved. JSON schemas and keys remain language independent.
- Official GRELECY logo in both headers and executable, window and taskbar icons.

Download **GRELECY-Diagnostics-0.3.0-preview.1-win-x64.zip**, extract it and open **GRELECY-Diagnostics.exe**. The target is Windows 10/11 x64; .NET is included and administrator rights are not required. The package includes its guide, licenses and Microsoft notices.

Automated checks cover catalogs, all 14 languages, reports, answer preservation, themes, high contrast, branding and Windows workflows, plus launching the distributed executable. Native-speaker translation review and acceptance checks with Narrator, display scaling and personal hardware remain pending. Native dialogs such as the file picker use Windows settings and translations.

This remains an **unsigned prototype**; Windows may show an unknown-publisher warning. It provides no driver, measures neither performance nor compatibility, and uploads no report automatically. Posting on GitHub is voluntary, public and requires an account. A successful test applies only to the scenario described.
