# GRELECY application artwork

`grelecy.ico` is a Windows icon generated from the official
[`grelecy-logo.png`](../../../assets/brand/grelecy-logo.png), preserving its
canvas, proportions, colors and transparency. It contains 16, 24, 32, 48, 64,
128 and 256 pixel representations for Windows shell and window display.

The application also embeds the original PNG directly from `assets/brand/` for
its headers. The artwork is not covered by the software's MPL-2.0 license or the
documentation's CC BY 4.0 license. The separate [brand policy](../../../BRANDING.md)
applies. No new logo design or recoloring is introduced.
